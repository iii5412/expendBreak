# Task 2: 홈 대시보드와 빠른 거래 입력

## 실행

`npx vite --host 127.0.0.1 --port 5188` 실행 후 `http://127.0.0.1:5188/budget-app.html`을 연다.

Task 1과 동일하게 기존 운영 앱과 분리한 개발용 진입점이다. `src/budget-app/`의 재사용 가능한 화면 컴포넌트를 Task 1 계산 코어에 연결했다. 원래 앱의 저장소·인증·보안 규칙·Android 버전은 변경하지 않는다. 기본 배포 빌드는 이 HTML을 포함하지 않는다. Firebase 연동은 아직 구현하지 않았고, 모든 변경은 React 메모리 상태에만 반영되어 새로고침하면 초기화된다. 날짜는 목업 시나리오인 2026-10-19로 고정되어 있다.

## 동작

- 홈, 내역, 중앙 추가 버튼, 분석 요약, 관리로 이동하는 하단 메뉴.
- 오늘 배정액 대비 당일 지출 비율 70%, 85%, 100% 경계의 신호등. 색과 함께 상태명·아이콘·문구를 표시한다.
- 이미 쓴 변동비, 미결제 예정 변동비, 안전 잔액의 3구간 예산 바. 한도 초과는 음수 안전 잔액과 초과 설명으로 표시한다.
- 현재 주기의 실제 거래 횟수로 배달·택시 쿠폰을 계산한다. 관리에서 목표 한도와 월 허용 횟수를 바꿀 수 있다. 과다 횟수는 초과 횟수로 표시한다.
- 기본 접힘 현금흐름에는 확정/예정 수입, 고정비 차감 후 금액, 예정 포함 순현금흐름, 예상 주기말 지출을 표시한다.
- 추가 모달은 숫자 패드, 5개 단골 원탭 저장, 수동 카테고리·가맹점 입력, 일회성 지출 토글을 제공한다. 모달 포커스 제한은 기본 HTML dialog를 사용하며 Escape로 취소하고 닫을 때 원래 버튼으로 포커스를 돌려준다.
- 금액 입력 때 저장에 사용하는 동일한 거래 초안을 계산 코어에 넣어 오늘 남은 금액·내일 예상 배정액을 미리 보여준다. 0원은 저장할 수 없다. 빠른 반복 클릭의 중복 저장은 ref 잠금으로 방지한다.

## 검증 시나리오

초기 오늘 배정액 36,923원, 오늘 지출 12,500원, 오늘 잔여 24,423원, 내일 예상액 38,958원, 배달 쿠폰 2장이다.

1. 추가에서 24,900원을 입력하면 오늘 잔여 -477원, 내일 예상액 36,883원을 미리 보여준다.
2. 일회성 지출을 선택하고 배민 칩으로 저장하면 오늘 배정액은 유지되고, 오늘 신호등은 초과로 전환되며 쿠폰은 1장 남는다.
3. 내역에서 일회성 배민 거래를 확인한다. 분석 요약의 일상 지출 속도는 기존 8,035원/일을 유지한다.
4. 현금흐름을 펼쳐 집계를 확인하고, 관리에서 쿠폰 0장·한도 0원도 시험한다. 360px과 데스크톱 화면 모두 가로 넘침 없이 사용할 수 있어야 한다.

자동 검증: `npm run lint`, `npm test`. 신호등 경계·쿠폰 제외 조건·한도 초과 예산 바·어제 절약 배지는 `src/budget-app/dashboard.test.ts`에서 검증한다.
