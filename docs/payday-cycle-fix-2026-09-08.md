# 급여 주기 교정 — 2026-09-08

## 반영한 기준

- 앱의 8월: 2026-08-10~2026-09-09. 9월: 2026-09-10~2026-10-09.
- 생활비, 남은 일수, 하루 안전금액, 지출 속도, 카테고리 분석, 거래내역 기본 조회, 주기 마감 보고서, AI 요약 모두 설정된 급여일을 사용한다.
- 카드 사용·다음 결제 예상액은 선택 월 1일~말일을 집계한다. 제공된 카드 3개의 결제일은 10일이고 별도 마감일은 없다. 따라서 9월 1~30일 사용액은 10월 10일 청구에 반영된다.
- 9월 1일 신용카드 사용은 8월 생활비에 포함되고, 10월 10일 카드대금에 포함된다. 카드대금 납부 기록은 생활비 소비로 다시 더하지 않는다.
- 기존 거래와 확정 카드 청구액은 수정하지 않는다. 기간별 조회와 계산을 교정한다.

## 원인과 수정 범위

생활비 계산에 `getAccountingPeriod(yearMonth, 1)`이 고정되어 있었다. 급여 회계 기간과 생활비 기간이 갈라지면서 9월 1~9일 지출이 8월 주기에서 빠지고 8월이 조기 마감되었다.

공통 요약·거래내역의 기간을 급여 회계 기간으로 연결하고, 홈·분석·마감·음성/채팅 카테고리의 1일 고정값을 제거했다. 카드 사용 요약은 별도로 달력 월을 지정하고 화면에 집계 기준을 표시했다. AI 분석 캐시 키에도 시작·종료 날짜를 넣었다.
